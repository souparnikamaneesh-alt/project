# Modern Glassmorphic Calculator

A beautifully designed modern calculator featuring tactile spring animations, dynamic radial ripple effects, seamless dark/light theming, sound synthesis, and calculation history.

![Calculator Preview](index.html)

---

## ✨ Features

- **Fluid Tactile Animations**:
  - Spring-release button presses (`cubic-bezier` bouncy physics).
  - Dynamic coordinate-aware radial ripple effect upon clicks.
  - Number display entrance and evaluation pulse animations.
  - Shake animation with red warning glow on invalid math (e.g., division by zero).
  - Floating ambient light orbs in the background.

- **Clean Modern Aesthetics**:
  - Glassmorphic translucent chassis with blurred backdrop reflection.
  - One-click **Dark / Light mode** toggle with smooth transitions.
  - Auto-scaling display text so long numbers never overflow or truncate.
  - Click-to-copy display output with a visual tooltip.

- **Smart Calculator Engine**:
  - Full arithmetic operations: addition (`+`), subtraction (`−`), multiplication (`×`), division (`÷`).
  - Edge-case precision handling (`0.1 + 0.2 = 0.3`).
  - Percentage calculations (`%`), sign negation (`±`), and backspace (`⌫`).
  - Persistent **Calculation History drawer** with click-to-recall values.

- **Full Keyboard Support**:
  - `0 - 9` and `.`: Input numbers.
  - `+`, `-`, `*`, `/`: Arithmetic operators.
  - `Enter` or `=`: Calculate result.
  - `Backspace`: Delete last digit.
  - `Escape`: All Clear (`AC`).
  - Visual keyboard feedback: pressing a physical key triggers the on-screen button animation and sound!

- **Web Audio Haptic Sound Effects**:
  - Synthesized micro-tones for clicks, operations, and result evaluations (toggleable with the speaker icon).

## 🚀 How to Run

Simply open `index.html` in any modern web browser:
- **Double click** `index.html` in Windows File Explorer, or
- Right click `index.html` > **Open with** > **Google Chrome** / **Microsoft Edge** / **Firefox**.
